# The website you build yourself?

This is a product website for your NEXT BIGGEST AI MODEL  
You NEED to make this landing page stick out from all of the models that come out  

Your goal is to create new website sections and prompt **GLM 5.3 Flash** *(as long as i have credits)* to generate the website  

LIVE DEMO: https://fim-thewebsite.onrender.com/  

*the website will be a blank screen untill someone types a prompt*

### Currently written:
* A website written in html and a server written in go
* An AI prompt window to add new stuff to the website
* An implemented ai model (currently glm 5.3 flash)
* Implemented [jev](https://typesafe.ai/) to check if generated section meet a certain quality standart
* Implemented a way to add history, let user write on top of each others sections
* Implemented a library for the AI to get materials generated before such as logo, description of the website, what is built, etc. etc. AND a way to read the websites code
